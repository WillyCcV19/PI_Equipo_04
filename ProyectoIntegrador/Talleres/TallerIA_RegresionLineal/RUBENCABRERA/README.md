# Taller de Regresión Lineal - Ruben Cabrera
En este taller aprendí a construir y evaluar modelos de regresión en Python. Primero hice un análisis exploratorio (estadísticas, histogramas y correlaciones) y luego entrené una regresión lineal múltiple para predecir el consumo de energía, donde Horas_Operacion resultó ser la variable más influyente. Validé los supuestos del modelo revisando que los residuos fueran normales y homocedásticos. Después usé datos sintéticos para entrenar un árbol de decisión, lo evalué con el MSE y vi qué variables eran más importantes. Por último, con statsmodels obtuve un R2 de 0.976 y usé los p-valores para confirmar que solo X1, X2 y X3 eran significativas. Así se pudo distinguir las variables que realmente influyen en un resultado de las que solo aportan ruido.
